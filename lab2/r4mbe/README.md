# Repository for LAB2: Design and Implementation of a R4MBE.
The process involves:
	- Design the architecture of the R4MBE composed by: modified booth encoder and wallace tree
	- Development using SystemVerilog for the description of the structural architecture of R4MBE
	- Simulation with Siemens QuestaSim in two step: first the stand-alone component, then included it in the FPU as the mantissa multiplier
	- Synthesis with Synopsys DC Compiler
	- Verify the netlist behaviour with Siemens QuestaSim
	-They can be found in the following folder: --> `r4mbe/`
# Usage
Note: the detailed output of each script is found inside the `log/` folder with the corresponding name 
- `sim/tb_mult.do` ----> runs the testbench with questasim in shell mode of R4MBE as a stand-alone component. This command
also outputs to the shell to check the simulation results. Must be run inside the `sim/` directory.
- `sim/tb.do` ----> runs the testbench with questasim in gui mode to simulate the whole FPU with the new mulitplier. Must be run inside the `sim/` directory.
- `syn/synth_ultra_script.scr` ----> runs the synthesis with Synopsys in shell mode of the whole FPU using the R4MBE
as the mantissa multiplier. The reports from this script of area and timing can be found inside the `syn/report` directory, while
the verilog netlist and sdf file can be found in the `netlist` directory. 
- `sim/tb_verNetlist.do` ----> runs the testbench with questasim in gui mode of netlist generated by synopsys. Must be run inside the `sim/` directory.
- `sim/verifyResults.sh` ----> run this script for verify the results generated by the netlist testbench.
